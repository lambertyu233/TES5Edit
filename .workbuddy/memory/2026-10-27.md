## 重构可行性讨论（用户提问）
- 结论：可行但不推荐 1:1 全量重写（数人年、回归风险高）。
- 关键：贝塞斯达插件解析已被重写进主流语言——C# 有 Mutagen（成熟、代码生成驱动定义），Rust 有 esmio 生态 + xTranslator 真实重写案例（Rust+Tauri+React）。
- 推荐路径：绞杀者模式 + 黄金测试集；优先复用 Mutagen(C#/.NET+Avalonia) 或 Rust+Tauri，只补 xEdit 独有功能（冲突解析/清理/脚本引擎）。
- 产出报告：`重构可行性分析.md`（仓库根目录）。

## MO2 + xEdit 整合包使用指南（用户提问）
- 产出：`MO2与xEdit整合包使用指南.md`（工作区根目录）。
- 核心结论（基于源码 xeInit.pas / wbCommandLine.pas 与 MO2 文档）：
  - xEdit 必须放在真实 Tools 目录（非 mods/、非 Data/），从 MO2 启动以走 USVFS 拿到合并后加载顺序。
  - 普通编辑加 `-IKnowWhatImDoing` 即可；`-SSE`/`-TES5` 指定游戏模式；`-moprofile` 是 MO1 老机制，MO2 不用。
  - 新建/另存插件默认落到 MO2 的 Overwrite，需整理成独立 mod；不要直接改整合包底层文件。
